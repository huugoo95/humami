# Task intake and closure

Before starting significant work (repository changes, production impact or more than about 15 minutes), state the objective and the done criteria. Extract what the request already says; ask only when missing information blocks the work.

Before closing:
- Check the done criteria against real evidence: tests, CI, production checks, URLs.
- Report the actual state: local, committed, merged, deployed, verified.
- Record durable decisions in [decisions](../../../../ops/decisions.md) and real incidents in [incidents](../../../../ops/incidents.md).
- For product features, update the OpenSpec tasks with evidence.
- Account for every worktree or branch created for the task.
